# CSS Basics

This repository contains examples and demonstrations of fundamental CSS concepts to help you learn how to style web pages effectively.

## What's Inside

- **Basic CSS examples**: Core styling properties and selectors
- **Layout techniques**: Flexbox, Grid, and positioning
- **Color demonstrations**: Different ways to work with colors in CSS
- **Responsive design**: Mobile-friendly styling patterns
- **Interactive examples**: HTML pages showcasing various CSS techniques

## Files Overview

- `index.html` - Main demonstration page
- `styles.css` - Primary stylesheet with basic CSS examples
- `styles-index.css` - Styles for the index page
- `styles-tips.css` - Additional styling tips and examples
- `tips.html` - Page with helpful CSS tips and tricks
- `CSSColors/` - Directory containing color-related examples

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/suman-shah/CSS-Basics.git
   ```

2. Open any HTML file in your browser to see the examples in action

3. Explore the CSS files to understand how different styles are applied

## How to Contribute

We welcome contributions! Here's how you can help:

1. **Fork the repository** - Click the 'Fork' button at the top right

2. **Clone your fork** to your local machine:
   ```bash
   git clone https://github.com/YOUR-USERNAME/CSS-Basics.git
   ```

3. **Create a new branch** for your changes:
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Make your changes** in the appropriate files:
   - Add new CSS examples to `styles.css`
   - Create new demonstration pages
   - Improve existing examples with better practices
   - Fix bugs or improve documentation

5. **Commit your changes**:
   ```bash
   git add .
   git commit -m "Add: brief description of your changes"
   ```

6. **Push to your fork**:
   ```bash
   git push origin feature/your-feature-name
   ```

7. **Create a pull request** - Go to the original repository and click 'New Pull Request'

## Contribution Guidelines

- Keep examples simple and well-commented
- Follow CSS best practices
- Test your code in multiple browsers when possible
- Include clear descriptions in your pull requests
- One feature/fix per pull request
